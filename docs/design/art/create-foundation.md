# 钢潮 · 美术基座分析（Create 视觉语言拆解）

> 数据获取：2026-11-05 ｜ 样本：`create-1.21.1-6.0.10.jar` 实测采样 + Modrinth 官方项目描述
> 用途：作为整合包主要美术元素的判定依据（贴图 / UI / 光影 / 新资产 / 光影分级）

---

## 0. 一句话结论

**Create 的美术不是"蒸汽朋克"，是"可见机械的暖工业"。**
官方自我定位就是这两个词：`Aesthetic Technology` / `Building, Decoration and Aesthetic Automation`
（Modrinth 项目描述原文，2026-11-05 读取）。

它对整合包的意义：**选 Create 当基座 = 把"暖"定成基色，把"可解释"定成纪律。**

---

## 1. 三个词先分清：蒸汽 / 工业 / 美学

| | 定义 | 视觉特征 | 危险 |
|---|---|---|---|
| **蒸汽朋克 Steampunk** | 维多利亚 + 蒸汽动力的浪漫主义 | 黄铜、护目镜、齿轮装饰、礼服、管道外露 | 装饰过剩，功能可疑，容易变成"黄铜贴纸" |
| **工业 Industrial** | 大规模生产的实用主义 | 钢、混凝土、铆钉、传送带、匿名 | 冷、无个性、变成 GregTech 的仪表盘 |
| **Create 的位置** | 工业的骨架 + 蒸汽朋克的暖色 + 手工作坊的尺度 | 每个齿轮真的在转、真的传应力 | —— |

**判定 Create 属于哪边的唯一标准是"装饰是否等于功能"。**
Create 的齿轮不是贴花，是传动件；管道不是装饰，是物流；飞轮不是造型，是应力缓冲。
它把"好看"绑死在"能用"上 —— 这是它和 90% 科技模组的分水岭。

> 对钢潮的直接推论：**任何装饰都必须能回答"它为什么在这"。** 答不出的装饰，砍掉。

## 3. 色彩纪律（从色板反推的五条规则）

1. **暖色主锁 H20–45**。木、黄铜、锈、旧皮革全在这条带里。整包约 60% 的像素应落在这。
2. **中性灰必须 S ≤ 3**。工业铁 S0–2、安山 S2–7。"灰"是**去彩色**，不是"浅色"。
3. **高饱和只给两处**：黄铜金（H38–43, S55–88）、铜红（H14–15, S43–59）。别处一律降。
4. **冷色的三种语义**（不能混用）：
   - 蒸汽 `H200–220` → 动力、排气、高温
   - 锌/合金 `H120–140 S≤16` → 结构件、承重
   - 铜绿 `H156–183` → 时间、氧化
5. **紫是禁区**。唯一例外 `shadow_steel`（H247–270, S3–11）—— 而且它被刻意压成"灰紫"，几乎无彩。

## 4. 构造语法（贴图直读的四条）

1. **框包芯**：每块机壳都是"外框金属 + 内部板条"。
   - 安山 = 灰石框 + 竖木条
   - 黄铜 = 金框 + 深褐木条
   - 铜 = 红铜框 + 灰板
   - 铁路 = 金厚框 + 深蓝黑圆（烟囱/车头意象）
   **没有一块 Create 方块是单一材质铺满的。**
2. **板条方向 = 运动方向**：竖条（上下）、横条（左右）、斜条（斜向传动）。贴图在暗示力往哪走。
3. **四角铆钉**：`industrial_iron_block` 四角有铆钉点 —— "组装"的视觉签名。
4. **圆优于方**：齿轮、飞轮、管道、转轴、螺旋桨。方块网格是限制，Create 在里面尽量塞圆。

## 5. 时间感（怎么表达"旧"）

| 手段 | 具体做法 | 反例（别做） |
|---|---|---|
| 氧化分级 | 铜走四级色阶 | 一步跳到青绿 |
| 接缝积垢 | 暗部只出现在**接缝、内凹、螺丝周围** | 整块蒙一层灰 |
| 锈色 | 暖棕 `H25` + 苔绿 `H83–109` 混 | 纯橙锈（太新） |
| 修补痕迹 | 用不同材质的补丁块 | 破洞（Create 不破，只修） |

**核心纪律：磨损永远在"结构线"上，不在"平面中央"。**
整块脏 = 贴图脏，不是东西旧。

## 6. 蒸汽：Create 里它是"视觉事件"，不是"物质"

实测 jar：

```
com/simibubi/create/content/kinetics/steamEngine/SteamJetParticle.class
com/simibubi/create/content/kinetics/steamEngine/SteamEngineVisual.class
com/simibubi/create/content/decoration/steamWhistle/WhistleBlock.class
assets/create/textures/particle/steam_jet_0..15.png   （16 帧循环）
assets/create/sounds/steam.ogg
assets/create/ponder/steam_engine.nbt / steam_whistle.nbt
```

**没有 steam 流体。** 蒸汽 = 粒子 + 声音 + 3D 教学 + 汽笛（能吹音符）。

这对整合包是**最大的美术抓手**：

- 它是画面里唯一的亮冷点（`#CBDBFC`），在暖车间里天然跳出来
- 它是"呼吸节奏"：一冲一收，跟机器转速绑定
- **怪潮来临 → 全厂满负荷 → 蒸汽喷得最猛**
- 于是：**蒸汽 = 这个整合包的紧张度仪表**

> 落地建议：把"工厂是否在满负荷"用蒸汽密度表达，比任何 HUD 都直观。这条几乎零成本（原版就有），但没有任何整合包做过。

## 7. UI 语言：工程师的台账，不是科技面板

Create 的界面是**纸**：`#FFFAEE` 工程纸 + `#4C3426` 木框 + 齿轮小图标 + `#A61F1F` 血红警示（占比 0.4%，用得极省）。

配套的是 **Ponder** —— 官方原话："Create's visual in-game documentation called 'Ponder'"，即**游戏内 3D 动画说明书**。

**对钢潮的直接指导**：

| 核心 UI 元素 | 别做 | 要做 |
|---|---|---|
| 血条 | 红色进度条 | 黄铜**压力表**，指针 + 刻度盘 |
| 燃料 | 电池图标 | **油位玻璃管** + 浮子 |
| 模块槽 | 九宫格 | **抽屉**，拉开有木轨 |
| 怪潮倒计时 | 数字时钟 | **气压计**，指针随临近往下压 |
| 词缀 | 彩色图标 | **做旧铜牌**，刻字 |
| 队列表 | 头像列表 | **值班表**，图钉钉在软木板上 |

**统一原则：所有信息都"记在纸上、装在铜框里、能用手摸"。**

## 8. 四色冲突与统一方案（钢潮实际装了什么）

| 来源 | 美术语言 | 冲突点 |
|---|---|---|
| **Create**（含附属） | 19 世纪暖工业 | 基准，不动 |
| **TaCZ 枪械** | 20 世纪现代战术：哑光黑、聚合物、光学镜 | 太新、太冷、太"塑料" |
| **TLM 女仆** | 日式二次元：高饱和、平涂、大眼 | 太萌、太亮、太"平" |
| **航空学 levitite** | 奇幻矿：青绿 / 珍珠粉 | 太"魔法"，会带偏整包 |

### 统一四原则（按成本从低到高）

**① 同一套做旧层（最便宜，先做）**
所有外来素材（枪、女仆皮肤、飞艇）统一过一遍：降饱和 15–25% → 接缝加暗部 → 边缘加氧化。
手段 = 资源包重绘 + 光影色彩分级，双管齐下。
目标：**让 TaCZ 的黑枪看起来"被修过"，让女仆的裙子看起来"洗过很多次"。**

**② 冷色预算制（最有效，零成本）**
同一画面同一时刻，只允许**一个**冷色源在发光：
- 平时 → 蒸汽（蓝白）
- 战斗 → 枪口焰（橙）+ 怪潮（紫黑）
- 预警夜 → 信标（冷青）

超过三个高饱和冷色同框，画面立刻散架。

**③ 圆角替换（中等成本，收益最大）**
把 UI 里所有"现代直角卡片"换成 Create 的**倒角木框 / 铜框**。
自研 Java GUI 是唯一能一次改到位的地方，优先做这里。

**④ 语义化奇幻（最贵，但决定上限）**
`levitite` 的青绿和珍珠粉**不能当魔法光效用**，要当"一种还没搞懂的工业材料"用：
装进轴承、接进管路、用脚手架围着、被工人搬来搬去。
**奇幻件必须被工业行为包住** —— 否则整包变魔法包。

同理女仆：给她**皮围裙、护目镜、工具腰带、油污**（TLM 支持自定义皮肤/模型），
她就从"日式萌"变成"车间技师"。**这是解决"二次元 × 工业"冲突的最佳答案，而且只需要换皮。**

## 10. 美术圣经（贴墙上的一句话）

> **所有东西都要能被问三个问题：谁用过它？谁能修它？力从哪来？**

- **谁用过它** → 磨损在接缝，不在平面（人是会碰边角的）
- **谁能修它** → 有螺丝、有铆钉、有能拆的盖板（拒绝一体成型）
- **力从哪来** → 传动可见，拒绝黑箱（这是 Create 的灵魂）

---

## 11. 三条红线

1. **不用紫** —— 除 `shadow steel` 那一档的高阶件，且压成灰紫。
2. **不用纯饱和原色** —— 红只给警示（`#A61F1F` 用量 ≤0.5%）、绿只给氧化、蓝只给蒸汽。
3. **不做发光装饰** —— Create 唯一的自发光是 blaze burner 的火焰，**那是火，不是霓虹**。
