# 钢潮 · 自研模组美术规范（跟随 Create 风格）

> 定稿 2026-11-05。范围：只约束 `modules/irontide` 这一个自研模组。
> Create / 航空学 / TaCZ / 女仆的材质**一律不动**（成本考虑，见 §0）。
> 色值全部取自 `create-foundation.md` 的实测色板，不另造色。

---

## §0 为什么不改别的模组

整合包的美术基座是 Create，但直接改别人 jar 里的贴图 = 每次模组升级都要重打补丁，
且和资源包优先级、光影、连锁挖矿渲染都有冲突面。所以：

- **借用**：Create 的方块自己带风格，玩家看得见的就是它。
- **跟随**：自研方块/界面按 Create 的色阶、构造语法、时间感去画。
- **插入**：奇幻件（航空学 levitite、女仆）不换贴图，用「行为包裹」——让它们在玩法上被工业流程包住，
  视觉冲突靠同框频率稀释。

只有一样东西必须是自己的：**核心方块和核心界面**，因为那是玩家盯得最久的东西。

## §2 核心方块 `irontide:andesite_core`（16×16，cube_all）

定稿贴图：`src/main/resources/assets/irontide/textures/block/andesite_core.png`
原件备份：`素材/设计图/andesite_core.before.png`

### 结构（从外到内）

| 环 | 像素 | 内容 | 色 |
|---|---|---|---|
| d=0 | 最外 1px | 描边 | `#3F3E42` |
| d=1 | 1px | 黄铜框 | `#C08F55`；左上三点 `#D7AA5E`、右下三点 `#85553B` |
| d≥2 | 12×12 | 暖木竖板条底板 | 2px 板 + 1px 缝，`#6A4F2E` / `#5A4326` / 缝 `#46331C` |
| 中央 | r≤5.2 | 黄铜法兰盘 | 主面 `#C08F55`，外圈倒角 `#85553B`，左上 7 点提亮 `#D7AA5E` |
| — | 45° ×4 | 螺丝孔 | `#3A2411`，落在 r=3.6 |
| — | r≤2.05 | 中心轴孔 | 孔 `#14100A`，孔缘 `#4A2E17` |
| — | 2×2 | 炉火 | `#E0752A` / `#7A2A0A` |

### 三条硬规矩（后面所有自研方块照抄）

1. **框包芯**：外圈一定有描边+框，内部一定不是纯色铺满。Create 没有一个方块是平涂的。
2. **明暗不斜切**：不要「上半亮、下半暗」一刀切，改「左上角几点亮、右下角几点暗」。
   16px 上斜切会露出拼接感，老大的第一版就踩过。
3. **只留一处活气**：整块只有中心 2×2 是亮的（炉火），别处不许发光。

### 为什么是这个方案（免得以后有人改回去）

试过并否掉的：

- **玻璃罩里装齿轮/炉火**：Create 的「芯」是机械件直接外露（shaft、cogwheel 本身就是机械），
  没有玻璃罩语法。而且 16px 下玻璃底 `#1B1D21` 会变成黑洞。
- **中央用菱形**：16px 的菱形会被描边吃成六边形，糊。原图那个橙菱形是程序画出来的占位，
  不是美术资产，可以换。
- **整块黄铜（土豪金）**：核心被 22 格安山机壳包围，整块金会跳得太狠，像贴纸。

最终判断依据：把核心放进 3×3 机壳里看，**能不能一眼分出来，又不像外来的**。
见 `素材/设计图/irontide-core-3x3.png`——安山壳里跳得出来，黄铜壳里靠「圆盘 vs 横条」的形差辨认。

### 编译（已实测跑通）

```bash
cd modules/irontide
export JAVA_HOME="/c/Program Files/Microsoft/jdk-21.0.10.7-hotspot"
export GRADLE_USER_HOME="C:/Users/25571/AppData/Roaming/modmind/gradle-runtime/cache"
./gradlew build -x test --offline
```

三个坑，缺一个就编不过：

1. **PATH 上的 java 是 1.8**，必须显式设 `JAVA_HOME` 指向 jdk-21.0.10.7-hotspot。
2. **GRADLE_USER_HOME 必须指到 modmind 的 cache**。默认 `~/.gradle` 和 `E:\ailian\工具\gradle-home`
   都没有 `net.neoforged:neoform-runtime:2.0.24`，会报 `No cached version ... available for offline mode`。
3. **`maven.neoforged.net` 在本机被 DNS 污染**（解析到 31.13.96.192 / 157.240.13.8，Meta 的 IP），
   所以不能去掉 `--offline`，去掉就是 1 分钟超时后失败。
